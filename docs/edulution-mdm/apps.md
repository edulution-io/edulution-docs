# Apps

![MDM Apps](/img/features/mdm-apps.png)

Der Bereich **Apps** listet alle Anwendungen, die in Relution zur Verteilung freigegeben sind:

| Spalte | Beschreibung |
|--------|--------------|
| **Name** | Anzeigename der App, mit Symbol |
| **Bezeichner** | Technischer App-Identifier (z. B. Bundle-ID) |
| **Version** | Freigegebene Version |
| **Typ** | App-Typ |
| **Entwickler** | Herausgeber der App |
| **Letzte Aktualisierung** | Zeitpunkt der letzten Änderung |

Über das Filterfeld suchen Sie nach dem Namen.

:::note[Lesender Zugriff]
Die Liste zeigt den Bestand aus Relution. Apps hinzufügen, freigeben oder auf Geräte verteilen geschieht weiterhin in der Relution-Konsole – edulution ändert hier nichts.
:::

:::tip[Nicht mit dem edulution-App-Store verwechseln]
Der [App-Store](../edulution-plattform/apps/app-store.md) in den Einstellungen bestimmt, welche **edulution-Apps** in der Plattform erscheinen. Dieser Bereich hier listet die **mobilen Apps**, die Relution auf die verwalteten Geräte ausbringt. Die beiden haben nichts miteinander zu tun.
:::
