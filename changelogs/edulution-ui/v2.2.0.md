## v2.2.0 | 2026-08-07 | edulution-ui

### Die neue Version 2.2 ist da!

Mit Version 2.2 steht ein umfangreiches neues Release von edulution.io zur Verfügung. Mail, Kalender, Umfragen, Klassenzimmer und zahlreiche weitere Bereiche wurden erweitert und verbessert.

#### ⚠️ Hinweis zum Update

- **MongoDB**: Diese Version nutzt Datenbanktransaktionen. Dafür muss MongoDB als Replica Set betrieben werden — bestehende Installationen benötigen eine einmalige Anpassung durch den Administrator. Die Schritte sind [in der Dokumentation](/docs/edulution-ui/upgrade/mongodb/replica-set) beschrieben.
- **Öffentliche Umfragen**: Eine öffentliche Abgabe wird künftig über einen persönlichen [Teilnahme-Code](/docs/edulution-ui/features/umfragen) wiedererkannt. Abgaben, die vor der Umstellung entstanden sind, lassen sich nicht mehr nachträglich bearbeiten.
- **DAV-Adressen**: Eine DAV-Adresse ohne den Pfad /dav bricht das Freigeben von Kalendern, ohne es zu melden; die Mail-App hat zusätzlich eine eigene DAV-Verbindung erhalten. Prüfen Sie die [Einstellungen](/docs/edulution-ui/administration/einstellungen) Ihrer Kalender-, Kontakte- und Mail-App.
- **LINBO**: Der Bereich LINBO ist nur noch für Globaladmins sichtbar, Speichern, Prüfen und Anwenden bleiben Global- und Schuladmins vorbehalten. Für alle anderen Rollen entfällt die Funktion.

#### ✨ Neue Features

- **Mail**: Nachrichten können in mehreren Tabs geöffnet werden
- **Mail**: Der Versand kann innerhalb einer konfigurierbaren Wartezeit rückgängig gemacht werden
- **Chat**: Eigene Nachrichten können bearbeitet und gelöscht werden
- **Veyon**: Webseiten und Anwendungen können auf ausgewählten Geräten gestartet, Textnachrichten an sie verschickt werden
- **Allgemein**: Die Suche findet Namen jetzt unabhängig von Umlauten und Sonderzeichen — „Muller“ findet „Müller“, „Schoen“ findet „Schön“
- **Allgemein**: Eigene Anwendungen können über Keycloak geschützt werden

#### 🚀 Verbesserungen

- **Mail**: Personen, Gruppen und Verteiler werden schneller und übersichtlicher gefunden — Eltern auch über den Namen ihres Kindes
- **Mail**: Formatierung und Gestaltung von HTML-Nachrichten bleiben erhalten
- **Mail & Kalender**: Die in edulution eingestellte Sprache wird nach SOGo übernommen
- **Kalender**: Sichtbare Kalender und Freigaberechte werden mit SOGo synchronisiert
- **Kalender**: Verdeckte Termine können in der Monatsansicht direkt angezeigt werden
- **Kalender**: Stundenplantermine lassen sich wieder öffnen, bearbeiten und verschieben
- **KI-Chat**: Sehr lange Unterhaltungen laufen weiter, statt abzubrechen — ältere Nachrichten werden dabei automatisch zusammengefasst
- **Allgemein**: Auswahlfelder für Personen und Gruppen wurden übersichtlicher gestaltet
- **Allgemein**: Die Einstellungen verfügen über eine neue Suche
- **Allgemein**: Die mobile Darstellung der Aktionsschaltflächen wurde verbessert
- **Allgemein**: Die Eltern-Kind-Zuordnung unterstützt schulübergreifende Verknüpfungen

#### 🔐 Sicherheit

- Die Zugriffs- und Rechteprüfung wurde in allen Bereichen der Anwendung überarbeitet und vereinheitlicht. Ein zeitnahes Update auf Version 2.2 wird empfohlen.

#### 🛠️ Bugfixes

- Darstellung von zitierten und weitergeleiteten E-Mails verbessert
- Verwaltung freigegebener Postfächer stabilisiert
- Sammelaktionen im Klassenzimmer aktualisieren wieder alle betroffenen Schülerkarten
- Mitgliedergruppen können wieder korrekt aus Projekten entfernt werden
- Verschiedene Fehler in Kalender, Umfragen und Listenverwaltung behoben
- WebDAV-Uploads und Linuxmuster-Anbindungen stabilisiert

#### ⚙️ Technische Verbesserungen

- Mail-Postfächer, Adressbücher und Geräteabfragen wurden durch Zwischenspeicherung und wiederverwendete Verbindungen spürbar beschleunigt
- Proxy-Konfigurationen werden automatisch geprüft und aktualisiert
- Veyon-Verbindungen reagieren zuverlässiger auf Verbindungsabbrüche
- Das API-Container-Image basiert nun auf Debian slim statt Alpine
